# Vinote

Vinote turns YouTube and Bilibili videos into study notes with clickable timestamps, organized in folders. A Mac app (Apple silicon).

Vinote 把 YouTube 和 B 站视频变成带可点击时间戳的学习笔记，并按文件夹整理。适用于 Apple 芯片的 Mac。

## Download / 下载

Get the `.dmg` from the [latest release](https://github.com/chengshuo-dai/vinote-releases/releases/latest), open it, and drag Vinote to Applications. The app updates itself after that.

从[最新版本](https://github.com/chengshuo-dai/vinote-releases/releases/latest)下载 `.dmg`，打开后把 Vinote 拖进“应用程序”。之后 Vinote 会自动更新。

This repository only hosts the app's builds and its update feed.
本仓库只用于发布安装包和自动更新文件。
